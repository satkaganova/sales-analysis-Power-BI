# sales-analysis-Power-BI
Interactive Power BI dashboard evaluating sales performance across different dimensions. The project includes a comprehensive ABC analysis to classify products/retail sites by revenue contribution, data modeling with DAX measures, and key business metrics visualization for strategic decision-making.
