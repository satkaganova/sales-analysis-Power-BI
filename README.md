# Power BI Sales Analysis Dashboard
Interactive Power BI dashboard developed as part of my Data Analytics training to analyze sales data across products, categories, customers, dates and warehouses.
Dashboard Overview
The dashboard includes:
* Sales report and key sales metrics
* Total number of sales
* Sales analysis by warehouses
* Number of sales and transactions by warehouse
* Product analysis
* Category analysis
* Sales share by category
* ABC analysis of products and sales

Analytical Approach
The project focuses on exploring sales data from different dimensions and presenting the results through interactive Power BI visualizations.
ABC analysis is used to classify products based on their contribution to sales.
Tools
* Power BI
* DAX
* Data Modeling
* Data Visualization
